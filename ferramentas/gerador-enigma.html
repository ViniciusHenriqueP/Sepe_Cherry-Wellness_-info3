Gerador do enigma

Digite a palavra-chave do prêmio. Esta página monta o email do "cofre da Cereja Podre" com a palavra cifrada. Depois é só colar o HTML no template do EmailJS.

Só letras e espaços; acentos são removidos. De 3 a 30 letras.

1. Prévia do email

2. HTML para colar no EmailJS

3. Configurar o EmailJS (uma vez só, ~5 min)

  1. Entre em emailjs.com com a sua conta Google. O plano grátis manda 200 emails por mês.
  2. Email Services → Add New Service → Gmail → Connect Account, autorize o Gmail que vai mandar os enigmas e clique em Create Service. Copie o Service ID.
  3. Email Templates → Create New Template. Na aba Content, clique em Edit Content → Code Editor, apague o que estiver lá e cole o HTML copiado acima. Preencha também:
    • Subject: O cofre da Cereja Podre
    • To Email: {{to_email}}
    • From Name: Cherry Wellness
    Salve e copie o Template ID.
  4. Em Account → General, copie a Public Key.
  5. Cole os três códigos no começo de Visual/JS/desafio-secreto.js, no lugar de COLE_....

Para trocar a palavra-chave depois, gere o HTML de novo aqui e substitua o conteúdo do template. O código do site não muda.
